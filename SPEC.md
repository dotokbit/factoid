# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ) НА РАЗРАБОТКУ MVP ANDROID-ПРИЛОЖЕНИЯ

**Название проекта:** Factoid (рабочее название)

## 1. КОНЦЕПЦИЯ
Factoid — локальное минималистичное Android-приложение-доска для структурирования атомарных фактов.
Приложение предназначено для пользователей, которым важно снижать нагрузку на рабочую память, в том числе людей с СДВГ, аутизмом и AuDHD.

**Главные принципы приложения:**
- отсутствие авторизации и облачной синхронизации;
- отсутствие обязательного подключения к интернету;
- мгновенный запуск и 100% локальное хранение БД на устройстве;
- простая навигация между стандартными экранами;
- отсутствие сложной графики, Canvas, 2D-Zoom и пространственных анимаций;
- минимизация технических рисков и потенциальных багов.

**Основная задача:** Пользователь должен максимально быстро записать отдельный факт, а затем расположить его в простой визуальной структуре, где каждый Блокнот представляет собой отдельный квадрат.

## 2. СТРУКТУРА ДАННЫХ
Иерархия приложения: Доска (Board) -> Группа (Group) -> Блокнот (Notebook) -> Заметка/Факт (Factoid). Отдельно: Хранилище (Inbox) и Корзина (Trash).

### 2.1. Доска (Board)
Изолированное пространство данных (например: Работа, Дом, Личные дела).
- Поля: уникальный ID, имя, дата создания.
- Все Блокноты и Factoid принадлежат конкретной Доске.

## 3. БЛОКНОТ (NOTEBOOK)
Основной визуальный объект Доски.
- Поля: уникальный ID, ID Доски, текстовое имя, индекс цвета (из палитры 12 цветов), дата создания, ID Группы (nullable).
- Визуальное представление: всегда отображается как квадрат (aspect ratio 1:1). Форма и размер квадрата не зависят от количества содержащихся Factoid.
- Короткий клик по Блокноту открывает отдельный экран со списком его Factoid.

## 4. ГРУППА (GROUP)
Только визуальное объединение Блокнотов. Не является папкой, не содержит вложенных папок и не меняет навигацию.
- Поля: уникальный ID, ID Доски, название, индекс цвета (из палитры), дата создания.
- Блокнот может находиться только в одной Группе либо не принадлежать ни одной.
- Визуальная логика: отображается как квадратная/прямоугольная рамка с заголовком и отступами вокруг принадлежащих ей Блокнотов. Блокноты внутри остаются отдельными квадратами. Пустое пространство внутри рамки — норма. Если Группа пустая (0 блокнотов), она отображается как пустая рамка минимального размера с заголовком.

## 5. РАСПОЛОЖЕНИЕ БЛОКНОТОВ НА ДОСКЕ
- Доска — вертикально прокручиваемая область.
- Элементы автоматически располагаются в сетке (без ручного drag-and-drop в MVP).
- Группы и Блокноты без группы располагаются на Доске согласно правилам сортировки.

## 6. СОРТИРОВКА
Два режима сортировки для текущей Доски (переключатель в меню или верхней панели):
1. По алфавиту (по названию).
2. По дате создания.

**Правила сортировки:**
- Группы сортируются между собой по выбранному правилу.
- Блокноты без Группы сортируются между собой по выбранному правилу.
- Блокноты внутри Группы сортируются только относительно других Блокнотов этой же Группы. Принадлежность к Группе не меняется.

## 7. FACTOID
Атомарная текстовая заметка без заголовка.
- Поля: уникальный ID, текст, ID Доски, ID Блокнота (null, если в Inbox), дата создания, дата последнего изменения, флаг `isDeleted` (нахождение в Корзине).

## 8. ЭКРАН ДОСКИ (ГЛАВНЫЙ ЭКРАН)
- **Верхняя панель:** имя текущей Доски, кнопка меню (Navigation Drawer или Dropdown), кнопка поиска.
- **Основная область:** прокручиваемая сетка Блокнотов и визуальных Групп.
- **Нижняя часть:** фиксированная FAB-кнопка «+».

## 9. ПЕРЕХОД В БЛОКНОТ
- Короткий клик по Блокноту открывает отдельный экран через Jetpack Navigation Compose.
- Возврат выполняется системной кнопкой Back или стрелкой Back в TopAppBar.

## 10. ЭКРАН БЛОКНОТА
- **Верхняя панель:** стрелка назад, имя Блокнота.
- **Основная область:** вертикальный прокручиваемый список Factoid. Каждый Factoid — отдельная визуальная карточка/плашка с отступами.
- **Взаимодействие с Factoid:**
    - *Короткий клик:* ничего не происходит (защита от случайных нажатий).
    - *Долгий тап:* открывает контекстное меню/диалог: «Редактировать», «Переместить» (в другой Блокнот или в Inbox текущей Доски), «Удалить» (перемещает в глобальную Корзину, `isDeleted = true`).

## 11. УПРАВЛЕНИЕ ГРУППАМИ
- **Создание:** долгий тап по свободному месту Доски -> контекстное меню «Создать группу» -> ввод имени.
- **Управление:** долгий тап по рамке/заголовку Группы -> «Переименовать», «Изменить цвет», «Удалить».
- **Удаление Группы:** удаляется только рамка. Блокноты внутри не удаляются, остаются на Доске и получают статус «без Группы». Factoid не меняются.

## 12. УПРАВЛЕНИЕ БЛОКНОТОМ
- Долгий тап по Блокноту открывает меню: «Переименовать», «Изменить цвет», «Добавить в группу» (выбор существующей или создание новой, либо убрать из группы), «Удалить».
- **Удаление Блокнота:** сам Блокнот удаляется, а все его активные Factoid автоматически перемещаются в Inbox текущей Доски (`notebookId = null`).

## 13. INBOX / ХРАНИЛИЩЕ
- Внеструктурное пространство для быстрого сохранения Factoid, уникальное для каждой Доски.
- Не отображается на сетке Доски, открывается из меню текущей Доски.
- Отображается вертикальным списком плашек. Доступные действия по долгому тапу: редактировать, переместить в существующий Блокнот, удалить в Trash.

## 14. БЫСТРЫЙ ВВОД
- Нажатие на FAB «+» на экране Доски открывает диалог/BottomSheet быстрого ввода.
- **Поля:** текстовое поле для факта, выбор назначения («Хранилище» — по умолчанию, «Существующий Блокнот», «Создать новый Блокнот» с вводом его имени), кнопка добавления. После добавления форма закрывается.

## 15. ПОИСК
- Поиск по тексту всех активных Factoid (`isDeleted = false`) текущей Доски.
- При клике на результат: поиск закрывается, открывается экран Блокнота этого Factoid (или экран Inbox, если `notebookId == null`).

## 16. УПРАВЛЕНИЕ ДОСКАМИ
- Через боковое/верхнее меню доступны: список Досок, переключение между ними, создание новой (сразу становится активной), переименование, удаление.
- **Удаление Доски:** необратимо, требует диалога подтверждения. Удаляет Доску, её Группы, Блокноты и все её Factoid (включая Inbox и Trash этой Доски).

## 17. TRASH / КОРЗИНА
- Глобальный раздел приложения (доступен из меню), где собраны все Factoid с `isDeleted = true`.
- **Действия с элементом:** «Восстановить» (выбор существующего Блокнота или Inbox исходной Доски; если исходная Доска удалена — выбор любой существующей Доски), «Удалить окончательно».
- **Очистка:** кнопка «Очистить корзину» с подтверждением (полное удаление из БД).

## 18. ЦВЕТОВАЯ СИСТЕМА
Фиксированная палитра из 12 мягких UI-оттенков на основе цветового круга Иттена (Желтый, Желто-оранжевый, Оранжевый, Красно-оранжевый, Красный, Красно-фиолетовый, Фиолетовый, Сине-фиолетовый, Синий, Сине-зеленый, Зеленый, Желто-зеленый).
- Цвета не слишком насыщенные, комфортные для глаз.
- Цвет текста поверх плашки автоматически выбирается (темный или светлый) в зависимости от светлоты фона для обеспечения контрастности.

## 19. ЭКСПОРТ И ИМПОРТ (BACKUP)
Доступны в разделе «Настройки» через Android Storage Access Framework (SAF).
- **Экспорт:** формирует один JSON-файл со всей базой данных (Доски, Группы, Блокноты, Factoid). Позволяет сохранить файл или отправить через системный Share.
- **Импорт:** выбор JSON-файла. Обязательное предупреждение о полной перезаписи текущих данных. После подтверждения валидирует JSON (при ошибке текущие данные не удаляются), очищает БД и восстанавливает данные из файла.

## 20. ПЕРВЫЙ ЗАПУСК
При первом запуске (если в БД нет ни одной Доски) автоматически создается и открывается Доска «Моя доска».

## 21. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ И ОГРАНИЧЕНИЯ
- **Стек:** Kotlin, Jetpack Compose (Material 3), Jetpack Navigation Compose, Room, Kotlin Coroutines, StateFlow/Flow, Kotlinx Serialization (или Gson) для JSON, Android SAF. Min SDK: API 26.
- **Архитектура:** MVVM (Compose UI -> ViewModel -> Repository -> Room Database).
- **Строго исключить из MVP:** облако, аккаунты, drag-and-drop, 2D-Zoom, Canvas, вложения/картинки/аудио, теги, Markdown, напоминания.

## 22. КРИТЕРИИ ГОТОВНОСТИ MVP
Работоспособность всех сценариев из пп. 8–20 полностью офлайн, без потери данных при перезапуске приложения.
